# Root Cause Analyses

Before implementing a feature or fixing a bug, search this directory and the GitHub wiki RCA index for related failure patterns.

A written RCA is required when a bug causes authorization bypass, data exposure, data corruption, repeated production failure, or a substantial user-visible outage. The fix issue and pull request must link the RCA. Blamelessly record the failed control, the root cause, why detection missed it, the corrective change, and prevention work.

No significant incidents have occurred in this project yet.
